# Image Prompts: Pioneers & Traditions

**Page:** `/pioneers`
**Style:** photorealistic photography, soft natural light, muted neutral palette, dignified and respectful. For named historical pioneers: representational portraits (NOT claimed likenesses of specific real people) — vintage, sepia-tinted or aged-paper feel where appropriate to the era. For collective traditions: scene images that evoke the practice. 1:1 square portraits suggested for pioneer-portrait style; 16:9 for scene images. Anchor: aged Japanese practitioner aesthetic where historical, calm contemporary practice where modern.

**IMPORTANT representational note:** None of these prompts should attempt to generate a photorealistic likeness of a specific named real person. Each prompt uses framing like "an elder Japanese man representing a..." so the image is clearly evocative, not a portrait claim.
